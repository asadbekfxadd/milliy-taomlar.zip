# MANGO (milliy taomlar) — сайт ресторана в Янгиюле

Next.js 14 + PostgreSQL. Публичный сайт с меню и заказами, админка по паролю, загрузка фото (WebP), уведомления в Telegram с кнопками статуса.

## Что внутри

| Страница | Что делает |
|---|---|
| `/` | Главная: плов с паром, сцена «Живая гастрономия», фирменные блюда, история, доставка |
| `/menu` | Меню по категориям, фильтры, карточка блюда с порциями, добавками, составом и аллергенами |
| `/cart` | Корзина и оформление: самовывоз или доставка, зоны, минимальная сумма, проверка полей |
| `/order/[id]` | Статус заказа для гостя, обновляется сам |
| `/story` | «Больше, чем еда»: 6 сцен, ваш текст и фото из админки |
| `/contacts` | Телефон, адрес, часы, зоны доставки, ссылка на карту |
| `/admin` | Заказы, блюда, категории, настройки, интеграции |

Цены в заказе **всегда пересчитываются на сервере** из меню в базе: из браузера приходят только id блюд, размер, добавки и количество.

Таблицы создаются автоматически при первом запросе, миграции запускать не нужно.

## Деплой на Railway

1. Залейте папку в GitHub (например, `asadbekfxadd/milliy-taomlar`):
   ```powershell
   cd C:\milliy-taomlar
   git init
   git add .
   git commit -m "MILLIY TAOMLAR site"
   git branch -M main
   git remote add origin https://github.com/asadbekfxadd/milliy-taomlar.git
   git push -u origin main
   ```
2. В Railway: **New Project → Deploy from GitHub repo** → выберите репозиторий.
3. В том же проекте: **New → Database → PostgreSQL**.
4. В сервисе сайта откройте **Variables** и добавьте:

   | Переменная | Значение |
   |---|---|
   | `DATABASE_URL` | `${{Postgres.DATABASE_URL}}` |
   | `ADMIN_PASSWORD` | ваш пароль для `/admin`, от 8 символов |
   | `SESSION_SECRET` | случайная строка от 32 символов |
   | `PUBLIC_URL` | адрес сайта, например `https://milliy-taomlar.up.railway.app` |

5. **Settings → Networking → Generate Domain**. Подставьте этот адрес в `PUBLIC_URL`.
6. Откройте `/admin`, войдите, заполните **Настройки** (телефон, адрес, часы, зоны) и поправьте **Блюда** (цены, фото). Нажмите «Сохранить и опубликовать».

Случайную строку для `SESSION_SECRET` в PowerShell можно получить так:
```powershell
-join ((48..57)+(97..102) | Get-Random -Count 64 | % {[char]$_})
```

## Telegram-уведомления

1. В Telegram напишите **@BotFather** → `/newbot` → получите токен.
2. Создайте группу для заказов, добавьте туда бота.
3. Узнайте id группы: напишите в группу любое сообщение и откройте
   `https://api.telegram.org/bot<ТОКЕН>/getUpdates` — нужное число в `chat.id` (у групп начинается с `-100`).
4. Добавьте в Railway:

   | Переменная | Значение |
   |---|---|
   | `TELEGRAM_BOT_TOKEN` | токен от BotFather |
   | `TELEGRAM_CHAT_ID` | id группы |
   | `TELEGRAM_WEBHOOK_SECRET` | любая случайная строка |

5. В `/admin → Интеграции` нажмите **«Отправить тест»**, затем **«Подключить кнопки»**.

Каждый новый заказ придёт в группу с кнопками «Принять / Готовится / Готов / Завершён / Отменить». Нажатие меняет статус и у гостя на странице заказа.

## Онлайн-оплата

Payme и Click на сайте честно помечены как «не подключено», гость платит при получении. Для подключения нужны договор мерчанта, ключи и серверная проверка платежей — это отдельный этап.

## Фото блюд

Загружаются в `/admin → Блюда → Изменить → Загрузить фото`. Сервер поворачивает фото по EXIF, уменьшает до 1800 px и сохраняет в WebP. Пока фото нет, показывается нарисованная кодом иллюстрация блюда.

Лучший результат: съёмка сверху, тёмный фон, тёплый свет.

## Локальный запуск

```powershell
npm install
copy .env.example .env   # и заполните DATABASE_URL, ADMIN_PASSWORD, SESSION_SECRET
npm run dev
```
